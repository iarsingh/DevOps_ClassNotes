# DevOps Overview

Introductory notes covering the "why" and "what" of DevOps before diving into specific tools.

## Contents

- `DEVOPS_OVERVIEW_NOTES.txt` — Why DevOps (shorter dev lifecycle, better collaboration,
  cost/efficiency gains), the typical SDLC phases (Requirement, Analysis, Design, Development,
  Testing, Deployment, Maintenance), and how Agile and DevOps relate.
- `SDLC.png`, `Waterfall-Phases.png`, `agile.png` — Diagrams contrasting Waterfall and Agile
  software development lifecycles.
- `DevOps-Tools.png` — A map of common tools across the DevOps toolchain (SCM, CI/CD,
  config management, containers, monitoring).
- `Slide1.png`, `Slide2.png`, `Slide3.png` — Supporting slide images from the intro session.
