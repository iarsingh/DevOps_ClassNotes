# Linux Fundamentals

Baseline Linux command-line notes used as prerequisite knowledge for the rest of the repo
(Ansible, Jenkins, Docker, and Kubernetes labs all assume this level of shell comfort).

## Contents

- `LinuxCommands` — Checking distro/version (`lsb_release -a`, `/etc/os-release`), identifying
  the current shell, how commands resolve to binaries on the OS, and other everyday Linux
  command-line basics.
