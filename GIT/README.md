# Git

Notes on version control fundamentals and Git/GitHub/BitBucket workflows used across the other
modules (Jenkins pipelines pull from these repos, Ansible/CI-CD examples reference these
branching strategies).

## Contents

- `GIT_NOTES.txt` — What a version control system is and why you need one, core Git concepts.
- `GITDevOPS`, `InClassNotes09March` — In-class walkthrough notes on using Git in a DevOps workflow.
- `BranchingStrategies`, `Branching-realtimeScenario.txt` — Common branching models (feature/release/hotfix)
  and a worked real-time branching scenario.
- `GIT-repo Example.txt` — Example of creating and working with a Git repo end to end.
- `SSH_GITHUB` — Setting up SSH key authentication for GitHub.
- `PushNoCredentials`, `AutomatingGITPush`, `REMOTE_Simultaneous_Push` — Automating pushes and
  handling simultaneous/remote pushes without repeated credential prompts.
- `BitBucket.txt` — Notes specific to BitBucket as a remote.
- `CommandHistory`, `git logfile` — Captured terminal history / log output from lab exercises.
- `Git-Architechture.png`, `DevOps pipeline.png`, `DevopspipelineAutomation.png` — Diagrams of
  Git's architecture and how it fits into a DevOps pipeline.
