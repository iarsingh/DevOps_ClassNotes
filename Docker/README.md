# Docker

Docker fundamentals through Swarm: installation, images, containers, networking, Compose, and
using containers as Jenkins build slaves.

## Contents

- `DOCKER_NOTES_LMS.txt` — Installation, Docker Hub image search/login, and core image/container
  command scenarios.
- `DockerSWARM_NOTES_LMS.txt`, `DockerStack.yml`, `dockerStack_NOTES` — Docker Swarm setup and
  stack deployment notes.
- `dockerfile.txt`, `Jenkins-docker-slave dockerfile` — Example Dockerfiles, including one for
  building a Jenkins slave image.
- `docker-compose-wordpress.yml`, `docker_compose_files.txt` — Docker Compose examples, including
  a full WordPress + database stack.
- `DockerNetworking` — Notes on Docker's networking modes/drivers.
- `ContainersAsJenkinsSlave` — Using Docker containers as dynamic Jenkins build agents.
- `COntainer&VolumeBackup` — Backing up container data/volumes.
- `DBContainerTesting`, `DBFile` — Running/testing a database inside a container.
- `YAMLEXAMPLE` — Generic YAML syntax reference used alongside Compose/Swarm files.
- `main.py.txt`, `index.html` — Small sample app files used to demonstrate containerizing an app.
