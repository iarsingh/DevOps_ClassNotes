# Ansible

Configuration-management notes and playbook examples using Ansible.

## Contents

- `AnsibleNotes_LMS.txt` — Lab setup notes: provisioning instances, configuring SSH
  (disabling password auth), and getting Ansible control/managed nodes talking to each other.
- `AnsibleTower Steps.txt` — Steps for working with Ansible Tower.
- `Jenkins_Ansible.txt` — Wiring Ansible into a Jenkins pipeline.
- `playbook-ex1.yml`, `Fileplaybook.yml`, `multiplePlays_PLAYBOOK.txt` — Example playbooks,
  including a file-management playbook and a playbook with multiple plays.
- `AddressbookPlaybook.txt` — Playbook example deploying an "address book" sample application.
- `NetworkPlaybookExample/` — Example playbook(s) targeting network configuration tasks.
- `AnsibleVault/` — Notes/examples on encrypting sensitive data with Ansible Vault.
- `Swam playbook.txt` — Playbook notes related to Docker Swarm provisioning via Ansible.
